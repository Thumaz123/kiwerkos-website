# KIWERK OS – Website

Dieses Repository ist für den **öffentlichen Quellcode** der Website [kiwerk-os.de](https://www.kiwerk-os.de/) vorgesehen.

Die Website besteht aus statischem HTML, CSS, JavaScript und Medien. Interne Projektunterlagen, Entwürfe, Backups und Zugangsdaten gehören **nicht** in dieses öffentliche Repository.

**Status:** GitHub-Repository vorbereitet. Die automatische Veröffentlichung auf dem bestehenden IONOS-Webspace ist noch nicht aktiviert. Ein Git-Push allein verändert die Live-Website aktuell nicht.
